# Raft 3D

Cartoonig-buntes Überlebensspiel für das Handy (Three.js, iPhone-Browser) und das KI-Agent-Team, das es baut.

- `PROJEKT.md`: Entscheidungen, Stand, nächste Schritte
- `TEAM.md`: Rollen, Übergaben, Abläufe
- `.claude/agents/`: die sechs Agents (Senior Owner, Leiter, Planer, Programmierer, Debugger, Techniker)
- `.claude/skills/raft3d-programmierung/`: Programmier-Skill
- `buero/`: Team-Seite fürs iPhone (Status, Postfach, Aufgaben, Projektstand)
- `pakete/`: Aufgabenpakete · `berichte/`: Berichte der Agents · `tests/`: Prüfungen

## Team-Seite auf dem iPhone
Adresse (nach Einrichten von GitHub Pages): `https://neidelbert.github.io/raft/buero/`

**Antworten direkt in GitHub** (einmalig einrichten):
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate.
2. Repository access: nur `neidelbert/raft`. Permissions: **Contents: Read and write**. Ablaufdatum nach Wunsch.
3. Token in der Team-Seite unter ⚙ einfügen, Speichern. Er bleibt nur in diesem Browser.

Ohne Token erzeugt die Seite einen Antworttext zum Kopieren in den Chat.
