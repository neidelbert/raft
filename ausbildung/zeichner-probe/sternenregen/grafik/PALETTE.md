# Palette „Sternenregen“

Haus-Stil (Umriss `#2b1d2e`, Licht von oben links), dazu eigene Nachtfarben.

| Rolle | Farben |
|---|---|
| Umriss | `#2b1d2e` |
| Spieler: Hemd | `#4fb3ff` → `#2275c9` |
| Spieler: Haare | `#f59a4e` → `#c85a1e` |
| Spieler: Hose, Schuhe | `#6b5a8e` → `#463a63`, `#7a4a2a` |
| Haut | `#ffd7b0` → `#f0a97a`, Wangen `#ff8a8a` (50 %) |
| Korb (Holz) | `#e0a865` → `#c58a4a` → `#7a4a2a`, innen `#5a3418` |
| Stern (Belohnung) | `#fff3a8` → `#ffc928` → `#d98a0b` |
| Stein (Gefahr) | `#c2b19c` → `#8f7a66` → `#5c4a3c` |
| Herz (Leben) | `#ff8a8a` → `#e8443a` → `#a8232a` |
| Himmel | `#120c33` → `#241a55` → `#3a2768` |
| Hügel | `#2e2058` → `#22184a`, vorn `#1f1640` → `#160f30` |
| Mond | `#f6f1dc` → `#ddd3ae` → `#b3a67e`, Schein `#e8e0ff` (25 %) |
| Kleine Sterne | `#fff6d8`, Deckkraft 35–80 % |

Regeln: Hintergrund dunkel und blass, nur Belohnungen sind gold-gelb (Mond bewusst blass-creme, damit er nicht mit Sternen verwechselt wird). Gefahr erkennt man an Form (kantig) und bösem Blick.
