# Paket T1 (Testpaket für den Programmierer-Agent)
Ziel: Eine Ebene mit einfachem Wasser und einem Würfel als Floß, der per Joystick auf dem iPhone gesteuert wird.
Gehört dazu: Wasserfläche (einfach, leicht bewegt), Würfel als Floß, virtueller Joystick links (Touch, Maus als Zusatz), Kamera in Vogelperspektive folgt dem Floß, Einstellwerte zentral.
Gehört nicht dazu: Bauen, Hai, Überlebenswerte, Sound, Speichern, Aktionsknöpfe.
Abhängig von: nichts
Technik-Frage: keine (Three.js 0.170.0 per Import-Map von cdn.jsdelivr.net)
Fertig, wenn: startet ohne Konsolenfehler; Joystick bewegt den Würfel in die gezogene Richtung, Loslassen stoppt; Kamera folgt; Code in kleine Module aufgeteilt; Werte in einer Konfigurationsdatei; Pixel-Ratio höchstens 2; Bewegung mit Delta-Zeit.
Testaufgabe: Auf dem iPhone öffnen, Joystick nach oben ziehen: Floß fährt nach oben (vom Bildschirm weg), Loslassen: Floß stoppt.
Freigegeben: 24.10.2026, Leiter (Testpaket)
